# Professional request form

- **Production file:** `public/js/request-professional/request-form.js`
- **Purpose:** Validates the anonymous email-first professional application form and submits multipart data to the trusted endpoint.
- **Data/security:** Browser validation is advisory; the HTTPS Function validates fields and file type/size, stores the private file, and queues email.
- **Verification:** Email-first onboarding evidence is recorded in `VERIFICATION_LOG.md`.
