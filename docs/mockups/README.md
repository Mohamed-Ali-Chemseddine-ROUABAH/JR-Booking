# Mockup References / References mockup

This folder contains the complete frontend reference set. Read these files together before implementing or changing a user-facing flow.

Ce dossier contient l'ensemble des references frontend. Lisez ces fichiers ensemble avant d'implementer ou modifier un flux visible par un utilisateur.

1. [MASTER_MOCKUP.md](MASTER_MOCKUP.md): binding visual system: tokens, typography, glass treatments, status language, icons and layout restraint.
2. [jr-booking-premium-mockup.html](jr-booking-premium-mockup.html): approved interactive prototype: screens, roles, menus, modals, responsive behavior and local mock data.
3. [IMPLEMENTATION_REFERENCE.md](IMPLEMENTATION_REFERENCE.md): mandatory extraction map from prototype behavior to production modules, data boundaries and verification requirements.

The final production frontend must look and behave like the interactive mockup for the same role and viewport. It must use the visual system from `MASTER_MOCKUP.md`, but it must replace local mock data and inline prototype logic with the modular production ownership defined in `IMPLEMENTATION_REFERENCE.md` and `docs/requirements/MASTER_SPECIFICATION.md`.

Le frontend de production final doit ressembler et se comporter comme le mockup interactif pour le meme role et la meme taille d'ecran. Il doit utiliser le systeme visuel de `MASTER_MOCKUP.md`, mais remplacer les donnees fictives locales et la logique inline du prototype par les modules de production definis dans `IMPLEMENTATION_REFERENCE.md` et `docs/requirements/MASTER_SPECIFICATION.md`.
