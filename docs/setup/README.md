# External Setup Guides / Guides de configuration externe

This folder contains step-by-step guides for human configuration in Firebase, Google Cloud, and other approved external providers. The overall gate and completion status remain in [the setup checklist](../requirements/SETUP_CHECKLIST.md); do not duplicate checklist items in a provider guide.

Ce dossier contient les guides pas a pas pour la configuration humaine dans Firebase, Google Cloud et les autres fournisseurs externes approuves. Le gate global et l'etat d'avancement restent dans [la checklist de configuration](../requirements/SETUP_CHECKLIST.md) ; ne dupliquez pas les elements de checklist dans un guide fournisseur.

Create one English kebab-case guide per provider or configuration flow. Each guide must name its prerequisite checklist items, console paths, non-secret configuration values, verification steps, and the production modules that depend on it. Never place credentials, API keys, tokens, or private URLs in this folder.

Creez un guide en anglais kebab-case par fournisseur ou flux de configuration. Chaque guide doit nommer ses elements de checklist prerequis, les chemins dans la console, les valeurs de configuration non secretes, les etapes de verification et les modules de production qui en dependent. Ne placez jamais d'identifiants, cles API, tokens ou URL privees dans ce dossier.
